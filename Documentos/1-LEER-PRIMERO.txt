------------------------------------------------------------
  QUÉ CONTIENE ESTA ACTUALIZACIÓN
------------------------------------------------------------

Esta entrega implementa v6.10 (3 DCEPI conciliados + re-aplicación
de fixes perdidos):

A) F1 — CARGA AUTOMÁTICA DEL JWT:
   El proceso principal ahora carga el JWT del CredentialManager
   automáticamente si se le pasa vacío. Si no hay JWT disponible,
   devuelve un error claro en vez de fallar con HTTP 401 sin
   explicación.

B) F2 — ELIMINAR ERRORES SILENCIADOS:
   Se eliminaron los dos try/except que ocultaban errores del
   enriquecimiento. Ahora, cuando el enriquecimiento falla, las
   pending_tasks llegan al agente (no se silencian).

C) F3 — ARNÉS WORKER BUN / SUBAGENTES:
   Cuando el Worker Bun cae (429, timeout), el proceso le entrega
   las pending_tasks al agente en menos de 5 segundos (antes
   esperaba hasta 30). El Worker Bun sigue intentando recuperarse
   en segundo plano. Cuando se recupera, los subagentes terminan
   su lote actual y el Worker Bun retoma el control.

D) F4 — RE-APLICACIÓN DE FIXES PERDIDOS:
   Se re-aplicaron los fixes de v6.8.1 (capturar fallback_tasks
   del retorno), v6.8.3 (verificar Worker Bun procesó bloques) y
   v6.8.4 (sin temas provisionales + funciones faltantes) que
   se perdieron del código local tras un reset.

Validación ejecutada:
   - Tests atómicos pipeline.py: PASS
   - Tests atómicos integrador_respuestas.py: PASS
   - Tests E2E test_v42_e2e.py: 30/30 PASS

------------------------------------------------------------
  SI TIENES PROBLEMAS
------------------------------------------------------------

Si algo falla al hacer git push, probablemente es porque no tienes
configuradas tus credenciales de GitHub en tu computadora.

Para configurarlas, ejecuta en la terminal:

   git config --global user.name "Tu Nombre"
   git config --global user.email "tu@email.com"

Y cuando hagas git push, te pedirá tu usuario y contraseña de GitHub
(o un token de acceso personal si tienes autenticación de 2 factores).

Si necesitas ayuda, dile al agente Z.ai:
"No pude hacer git push. Ayúdame a configurar mis credenciales de GitHub."
